## Ask your current assistant to guide you

Send your assistant the address of this guide or its public GitHub repository, followed by this message:

```text
Read the Agentic Desktop Starter Guide at the link I just shared. First determine whether I am setting up a Mac or Windows computer, then choose the route that matches you as my current assistant. Guide me through it one action at a time. Assume I can install desktop apps and navigate folders, but I do not use command-line applications. Wait for me to confirm each action before continuing. When the selected project folder and its Codex chat or Claude Code session are ready, clearly tell me to stop using this setup conversation and switch to the Codex chat in the ChatGPT desktop app or the Claude Code session in the Code tab of the Claude desktop app. End your guidance at that point; the coding chat or session will continue from the handoff prompt.
```

You can also follow the pages yourself. The instructions are the same.

## What you need

<ul class="compact-list">
  <li>A ChatGPT account with Codex access, or a Claude subscription with access to the Code tab</li>
  <li>A supported Mac or a Windows 11 PC</li>
  <li>A computer account allowed to install applications</li>
  <li>A reliable internet connection</li>
  <li>About 30-45 minutes</li>
</ul>

<div class="notice">
  <strong>Desktop-only means no user-operated command line.</strong>
  The coding agent will run a few commands through its Codex chat or Claude Code session, using the selected project folder as the working directory. Depending on the app and permission mode, it may change files in that folder without asking each time. That is why this guide selects one new, empty project folder instead of a broad personal folder.
</div>

## What you will make

Your first project is a personal start page that runs only on your computer. You will choose its title, links, and appearance. The agent will create it, start it, and show it in a browser. Then you will ask for a change and watch the agent revise it.

The result is not published to the web, no website account is needed, and the example does not install third-party code packages. The desktop agent still sends your prompts and relevant project content to its AI service, so keep sensitive information out of the folder.

## The whole journey

1. Install the desktop app that matches your account.
2. Sign in with the same account you already use.
3. Give the app access to one new, empty project folder.
4. End the setup conversation and switch to the Codex chat or Claude Code session in the desktop app.
5. Install Node.js with its normal graphical installer if it is missing.
6. Build and revise your personal start page.

Before beginning, read the [five safety rules](https://tokintmash.github.io/ai-guide/safety/). They are short and apply to any coding agent.
