## Ask your current assistant to guide you

Send your assistant the address of this guide or its public GitHub repository, followed by this message:

```text
Read the Agentic Mac Starter Guide at the link I just shared. I use you as my current assistant, so choose the matching setup route. Guide me through it one action at a time. Assume I can install Mac apps and navigate folders, but I do not use Terminal. Wait for me to confirm each action before continuing.
```

You can also follow the pages yourself. The instructions are the same.

## What you need

<ul class="compact-list">
  <li>An active ChatGPT subscription for the Codex route, or an active Claude subscription with Claude Code access for the Claude route</li>
  <li>A Mac account allowed to install applications</li>
  <li>A reliable internet connection</li>
  <li>About 30-45 minutes</li>
</ul>

<div class="notice">
  <strong>Desktop-only means no user-operated Terminal.</strong>
  The coding agent will run a few commands inside its own workspace. Depending on the app and permission mode, it may change files in the selected project folder without asking each time. That is why this guide gives it one new, empty folder rather than broad access to your Mac.
</div>

## What you will make

Your first project is a personal start page that runs only on your Mac. You will choose its title, links, and appearance. The agent will create it, start it, and show it in a browser. Then you will ask for a change and watch the agent revise it.

The result is not published to the web, no website account is needed, and the example does not install third-party code packages. The desktop agent still sends your prompts and relevant project content to its AI service, so keep sensitive information out of the folder.

## The whole journey

1. Install the desktop app that matches your subscription.
2. Sign in with the same account you already use.
3. Give the app access to one new, empty project folder.
4. Hand the setup conversation to the local coding agent.
5. Install Node.js with its normal Mac installer if it is missing.
6. Build and revise your personal start page.

Before beginning, read the [five safety rules](safety/). They are short and apply to any coding agent.
